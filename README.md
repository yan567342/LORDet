# LORDet
LORDet

Official implementation of LORDet for lightweight oriented object detection in remote sensing.

Code Availability

The source code of LORDet will be publicly released in this repository upon acceptance of the associated paper. The repository will be updated with the implementation and instructions for installation, training, and evaluation.

Paper

Title: LORDet: Lightweight Oriented Object Detection for Remote Sensing via Direction-Aware Encoding and Critical-Scale Dynamic Fusion

Status

The source code is currently under preparation and will be made publicly available upon paper acceptance.
